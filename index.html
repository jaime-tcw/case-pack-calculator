How to Use
  1. Enter each SKU's current Amazon inventory Need (0 = exclude).
  2. Set Priority: 1 = High (round up), 2 = Normal, 3 = Low (round down OK).
  3. Check the Suggested Cases value, then set Number of Cases.
  4. Click Auto-Distribute or manually adjust Per Case until the check shows ✓.
  5. The Diff column shows over (+) or under (−) vs. need.
